# РП — Распределённое программирование

## Лабораторные работы

- [Лабораторная работа №1 — Valuator](lb1/README.md): ASP.NET Core Razor Pages, оценка текста и поиск дубликатов в Redis.
- [Лабораторная работа №2 — Nginx](lb2/README.md): два экземпляра Valuator, балансировка нагрузки, автоматизация запуска и останова.
- [Лабораторная работа №3 — RabbitMQ](lb3/README.md): асинхронный расчёт ранга, конкурирующие обработчики RankCalculator и C4-диаграмма.
- [Лабораторная работа №4 — Publisher–Subscriber](lb4/README.md): события вычислений, два независимых EventsLogger и C4-диаграмма.
- [Лабораторная работа №5 — SignalR](lb5/README.md): WebSocket-уведомления браузеру и обновление Summary без перезагрузки.
- [Лабораторная работа №6 — Сегментирование Redis](lb6/README.md): страны, три региона и центральная карта сегментирования.
- [Лабораторная работа №7 — Безопасность](lb7/README.md): парольная защита Redis/RabbitMQ, регистрация и доступ к результатам только для автора.

Инструкции запуска и проверки находятся в папке соответствующей лабораторной.
